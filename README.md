# Электронные Цифровые Подписи (ЭЦП)
## Электронная цифровая подпись (ЭЦП) — это метод подтверждения подлинности документа или транзакции с использованием криптографии. Она обеспечивает следующие ключевые свойства:

Аутентификация: подтверждает личность подписанта.
Целостность: гарантирует, что документ не был изменен после подписания.
Неотказуемость: подписант не может отказаться от своей подписи.
## Как работает ЭЦП?
Генерация ключей:
Генерируются два ключа: приватный (закрытый) и публичный (открытый). Приватный ключ используется для создания подписи, а публичный — для её проверки.
Хэширование данных:
Документ преобразуется в уникальный хэш-код (например, с использованием SHA-256).
Создание подписи:
Хэш-код шифруется с помощью приватного ключа.
Проверка подписи:
Подпись расшифровывается с помощью публичного ключа.
Вычисляется новый хэш-код полученного документа.
Новый хэш-код сравнивается с расшифрованной подписью. Если они совпадают, документ считается подлинным.
## Реализация на Python. Мы реализовали две версии ЭЦП на Python:

####RSA (rsa.py):
Использует асимметричную криптосистему RSA для создания и проверки подписей.
Подходит для случаев, когда важна простота реализации и поддержка больших документов.
####ECDSA (ecdsa.py):
Применяет алгоритм Elliptic Curve Digital Signature Algorithm (ECDSA), основанный на эллиптических кривых.
Обеспечивает высокую производительность и безопасность даже при меньших размерах ключей.
